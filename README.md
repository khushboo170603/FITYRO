# 👗 FITYRO - AI Virtual Trial Room

FITYRO is an AI-powered Virtual Trial Room that allows users to visualize clothing on themselves before purchasing. The platform combines Computer Vision, Artificial Intelligence, and modern web technologies to provide an interactive and personalized online shopping experience.

---

## 🚀 Features

### User Features
- User Registration & Login
- Secure Authentication
- Upload Personal Images
- Browse Clothing Collection
- AI-Powered Virtual Try-On
- User Profile Management
- Responsive Design

### Admin Features
- Admin Dashboard
- Product Management
- User Management
- Analytics & Insights
- Inventory Monitoring

### AI Features
- Virtual Clothing Try-On
- Human Pose Estimation
- Image Processing
- Garment Alignment
- Realistic Outfit Visualization
